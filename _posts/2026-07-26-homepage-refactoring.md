这个主页最初基于 AcadHomepage 学术模板搭建——它为科研人员设计，核心组件是 Google Scholar 引用统计和论文列表。但我的身份是工程师和技术写作者，学术组件长期闲置，而真正能代表我的开源项目、技术文章、社区活动却没有展示的位置。于是有了这次重构。

## 重构前的三个问题

1. **模板气质错位**：学术主页的信息架构（Publications、Scholar 引用）与工程师作品集的诉求（Projects、Writing、Activities）不匹配；
2. **站外影响力与站内呈现不对称**：多年在 CSDN、掘金、各云厂商社区的内容积累，在主页上几乎不可见；
3. **博客板块空转**：只有模板自带的测试文章，没有承接真实的内容生产。

## 重构方案

### 信息架构

导航从单一的 Blog 扩展为多板块结构：

```
Home | Projects | Activities | Blog
 ├─ About Me（精炼简介 + 影响力徽章）
 ├─ Projects（开源项目卡片）
 ├─ Activities（活动时间线）
 └─ Blog（文章时间轴）
```

首页的定位从"简历"转变为"作品集橱窗"：第一屏让访客快速了解我是谁、在做什么、做过什么。

### 图片资源规范

所有图片按类别分目录存放，统一 kebab-case 命名：

```
images/
├── projects/      # {项目名}-{内容}-{序号}.webp
├── activities/    # {YYYY-MM-DD}-{活动名}-{序号}.webp
├── certs/         # {年份}-{颁发方}-{证书名}.webp
├── badges/        # {平台}-{用途}.svg
└── site/          # favicon、头像等站点资源
```

固定语义词（封面 `cover`、演示 `demo`、序号 `-01`）让引用路径可以直接推导，不需要翻文件夹。

### 技术取舍

- **继续使用 Jekyll + GitHub Pages**：托管免费、部署零运维，对以内容为主的个人站点足够；
- **复用而非重写**：项目卡片改造自模板已有的 paper-box 双栏样式，活动时间线复用了博客时间轴的实现，几乎没有新增 CSS 负担；
- **动态数据用 shields.io 徽章**：GitHub stars/followers 等数据自动更新，避免手工维护截图。

## 后续计划

- 逐步把技术文章的精选内容沉淀到站内（注明首发平台）；
- 项目发布、活动参与后及时更新对应板块；
- 接入访问统计，用数据驱动信息排序的迭代。

重构不是终点，持续运营才是。这个站点接下来会作为我所有技术输出的索引与归档。
